## Redaction Notes  
To protect those environments these scripts belong to, I redacted sensitive information. So for example, you may see a string in the format "C:\Sample\file.csv". If the string (folder path in this case) was set to correctly represent something in the environment, the script would run correctly. You'll also see \[REDACTED\] in other cases.
